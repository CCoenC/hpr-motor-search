# Pit Board

Look up a high-power motor — I115, J350, White Lightning, 54 mm — and see which vendors have it, the price, how many are on the shelf, when that page was last checked, and the thrust curve.

Stock, price, and quantity come from the public hourly vendor snapshot at https://motor.fusionspace.co/api/v1/motors.json (AeroTech, Cesaroni, Loki across the usual U.S. shops). Specs and thrust curves come live from the ThrustCurve.org API.

The snapshot does not include a separate restocked-on timestamp. Pit Board shows last checked — when that vendor listing was scraped — and the quantity the page published.

Extras: value sort ($ / N·s), rocket fit by mount diameter and cert, compare up to three motors with overlaid curves, a star list, and an order pile you can copy.

Confirm price and stock on the vendor page before you pay. Scrapes go stale.
